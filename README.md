# 🎮 NHANH TAY LẸ MẮT – Luyện Thao Tác Chuột Máy Tính

Web app giáo dục tương tác cao dành cho học sinh tiểu học (Lớp 1 – 5) trong môn Tin học, rèn luyện 6 kỹ năng thao tác chuột máy tính cơ bản và nâng cao thông qua **20 bài tập trò chơi** hoạt hình sinh động, hấp dẫn.

## 🌟 Tính Năng Nổi Bật

- **20 Trò chơi luyện chuột hoàn chỉnh** chia làm 6 nhóm năng lực:
  1. **Nhóm A (Di chuyển & Trỏ chuột - Hover):**
     - Bài 1: *Cây đũa phép nhiệm màu* (Thắp sáng xứ sở cổ tích)
     - Bài 2: *Ong vàng chăm chỉ* (Hút mật hoa rừng)
     - Bài 3: *Đom đóm hoàng hôn* (Chiếc đèn lồng thần kỳ)
     - Bài 4: *Phi thuyền thám hiểm vũ trụ* (Kết nối các chòm sao)
  2. **Nhóm B (Nháy chuột trái - Single Left Click):**
     - Bài 5: *Cung thủ tí hon* (Bắn bia hoa quả)
     - Bài 6: *Đập chuột chũi tinh nghịch*
     - Bài 7: *Tiệm bánh ngọt diệu kỳ* (Nháy chuột chọn lọc theo đơn hàng)
     - Bài 8: *Bắn pháo hoa rực rỡ*
     - Bài 9: *Phím đàn thần kỳ* (Giao hưởng rừng xanh theo nhịp)
  3. **Nhóm C (Nháy đúp chuột - Double Click):**
     - Bài 10: *Giải cứu thú cưng pha lê* (Gõ nháy đúp phá vỡ pha lê)
     - Bài 11: *Mở cánh cửa sổ kỳ diệu*
     - Bài 12: *Đào kho báu hoàng gia*
  4. **Nhóm D (Nháy chuột phải - Right Click):**
     - Bài 13: *Vòng phép thuật biến hình* (Mở vòng bùa chú bằng chuột phải)
     - Bài 14: *Hộp quà bí mật* (Menu ngữ cảnh chuột phải)
  5. **Nhóm E (Kéo và thả - Drag & Drop):**
     - Bài 15: *Dọn dẹp phòng đồ chơi*
     - Bài 16: *Cho thú cưng ăn*
     - Bài 17: *Ghép tranh ghép hình thần kỳ*
     - Bài 18: *Kéo chọn vùng đối tượng*
  6. **Nhóm F (Con lăn chuột & Thử thách tổng hợp):**
     - Bài 19: *Tàu ngầm thám hiểm đại dương* (Cuộn lăn chuột lặn sâu / nổi lên)
     - Bài 20: *Nhà vô địch chuột máy tính* (Thử thách tổng hợp đỉnh cao)
- **Cấu trúc mỗi bài tập:** 3 Màn (Dễ, Vừa, Khó), mỗi màn 2 vòng chơi phong phú.
- **Hệ thống gợi ý 3 cấp:** Cấp 1 (Chỉ tay phát sáng), Cấp 2 (Bóng nói linh vật), Cấp 3 (Con trỏ ảo chạy mẫu).
- **Âm thanh tổng hợp Web Audio API thuần:** Không phụ thuộc tệp âm thanh ngoài, chạy mượt mà trên mọi thiết bị.
- **Cổng Đăng Nhập & Bảo Mật Kiểm Soát Cấp Phép:** Chỉ cho phép 10 tài khoản được phê duyệt truy cập.
- **Trang Quản Trị Giáo Viên:** Quản lý bảng điểm học sinh, bật/tắt từng bài tập, xuất báo cáo Excel/CSV.

## 🚀 Hướng Dẫn Đưa Lên GitHub & Xuất Bản Web App Miễn Phí (GitHub Pages)

### Bước 1: Tạo Repository mới trên GitHub
1. Đăng nhập vào tài khoản [GitHub](https://github.com/).
2. Nhấp vào dấu **`+`** ở góc trên bên phải → chọn **`New repository`**.
3. Đặt tên repository (ví dụ: `nhanh-tay-le-mat`), chọn chế độ **Public**, rồi nhấn **`Create repository`**.

### Bước 2: Đẩy toàn bộ mã nguồn lên GitHub
Mở cửa sổ dòng lệnh (Terminal / Command Prompt / Git Bash) tại thư mục dự án và chạy các lệnh sau:

```bash
# Khởi tạo git (nếu chưa có)
git init

# Thêm tất cả các tệp vào git
git add .

# Tạo commit đầu tiên
git commit -m "Phát hành ứng dụng Nhanh Tay Lẹ Mắt v1.0"

# Đổi nhánh chính thành main
git branch -M main

# Liên kết với repository GitHub của bạn (thay thế URL bằng link repo của bạn)
git remote add origin https://github.com/<TEN-TAI-KHOAN-CUA-BAN>/nhanh-tay-le-mat.git

# Đẩy code lên GitHub
git push -u origin main
```

### Bước 3: Kích hoạt GitHub Pages (Tự động chạy qua GitHub Actions)
Dự án đã được cấu hình sẵn tệp tự động `.github/workflows/deploy.yml`. Bạn chỉ cần:
1. Vào repository của bạn trên GitHub.
2. Bấm vào tab **`Settings`** (Cài đặt) ở thanh menu trên cùng.
3. Ở cột bên trái, chọn mục **`Pages`**.
4. Tại phần **`Build and deployment`** > **`Source`**, chọn **`GitHub Actions`**.
5. Chờ khoảng 1 - 2 phút, GitHub Actions sẽ tự động biên dịch và tạo đường link web app có dạng:
   👉 `https://<TEN-TAI-KHOAN-CUA-BAN>.github.io/nhanh-tay-le-mat/`

## 💻 Hướng Dẫn Chạy Cục Bộ (Local Development)

Nếu bạn muốn chạy thử nghiệm trên máy tính của mình:

```bash
# 1. Cài đặt các thư viện cần thiết
npm install

# 2. Khởi chạy máy chủ phát triển
npm run dev
# Mở trình duyệt và truy cập: http://localhost:3000

# 3. Đóng gói bản xuất bản chính thức (Production Build)
npm run build
# Tệp xuất bản sẽ nằm trong thư mục: ./dist
```
